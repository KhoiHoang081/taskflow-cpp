# Những phần bạn có thể tự phát triển

Các mục dưới đây CHƯA được cài đặt; mỗi mục phù hợp với một lần cải tiến thực tế.

- [ ] Thêm lệnh edit ID "TITLE" và test tiêu đề rỗng.
- [ ] Thêm list --sort priority; thống nhất cách xử lý khi cùng độ ưu tiên.
- [ ] Thêm trường deadline và kiểm tra ngày hợp lệ.
- [ ] Thêm lọc theo từ khóa kết hợp trạng thái.
- [ ] Lưu bộ đếm nextId để không tái sử dụng ID đã xóa.
- [ ] Ghi ra file tạm, thay thế an toàn và tạo bản sao lưu.
- [ ] Thêm chế độ menu tương tác với vòng lặp và xử lý EOF.
- [ ] Xuất CSV, xử lý dấu phẩy và dấu ngoặc kép đúng quy tắc.

Với mỗi mục: mô tả hành vi → sửa code → thêm test có ý nghĩa → chạy test →
cập nhật README → commit. Không cần hoàn thành tất cả cùng ngày.
